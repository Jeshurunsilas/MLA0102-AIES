1. Start
2. Create an empty priority queue OPEN.
3. Insert the start node into OPEN.
4. Set its priority as h(start).
5. Create an empty set CLOSED.
6. Repeat while OPEN is not empty:
      a. Remove the node n with the smallest h(n).
      b. If n is the goal:
            i. Construct the path using parent nodes.
            ii. Return the path.
      c. Add n to CLOSED.
      d. For each successor s of n:
            i. If s is not in CLOSED:
                  - Calculate h(s).
                  - Store n as the parent of s.
                  - Insert s into OPEN according to h(s).
7. If OPEN becomes empty:
      Return "No path found".
8. Stop.
