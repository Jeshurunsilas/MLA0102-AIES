
Start the program.
Define family members as male or female.
Define the parent-child relationships using facts.
Define rules to infer:
Father = Male + Parent
Mother = Female + Parent
Brother = Male + Same Parent
Sister = Female + Same Parent
Sibling = Same Parent
Grandparent = Parent of a Parent
Grandfather = Male Grandparent
Grandmother = Female Grandparent
Accept a query for a required family relationship.
Prolog matches the query with the stored facts and rules.
If the relationship is satisfied, return true or the matching family member.
Otherwise, return false.
Stop.
